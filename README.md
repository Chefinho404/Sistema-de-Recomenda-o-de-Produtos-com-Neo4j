# Sistema-de-Recomenda-o-de-Produtos-com-Neo4j
Desenvolvi um sistema de recomendação de produtos utilizando Neo4j e Cypher. O projeto explora a modelagem de dados em grafos, criação de nós, labels, propriedades e relacionamentos. Também implementei consultas para analisar compras e identificar recomendações, colocando em prática conceitos de bancos de dados orientados a grafos.
